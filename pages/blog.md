# blog

```language-content
::en
Use the **filters** to narrow posts by *tag* or *year*.

Write a sentence or two about what you write about. Posts live in the `posts/` folder as markdown files; run `npm run build` to refresh the index.

::fr
Utilisez les **filtres** pour affiner les articles par *tag* ou *année*.

Écrivez une phrase ou deux sur les sujets que vous abordez. Les articles sont des fichiers markdown dans le dossier `posts/` ; lancez `npm run build` pour mettre l'index à jour.

::zh
使用**筛选器**按*标签*或*年份*查找文章。

用一两句话说明你写些什么。文章是 `posts/` 文件夹中的 markdown 文件；运行 `npm run build` 刷新索引。

::ja
**フィルター**で*タグ*や*年*ごとに記事を絞り込めます。

どんなことを書いているか、一、二文で。記事は `posts/` フォルダの markdown ファイルです。`npm run build` でインデックスを更新します。

::it
Usa i **filtri** per restringere gli articoli per *tag* o *anno*.

Scrivi una o due frasi su ciò di cui scrivi. Gli articoli sono file markdown nella cartella `posts/`; esegui `npm run build` per aggiornare l'indice.
```
